## 📱 About SnapInsta Android App

## 📥 How to Use

1. Copy the URL of any public Instagram Reel, Story, or Post.
2. Open the **SnapInsta App** or visit [TheSnapInsta Web Tool](https://thesnapinsta.com/en).
3. Paste the copied link into the input box and tap **Download**.
4. Save the original clean MP4 or JPG file directly to your device storage.
